# Loopy

Loopy is a responsive artist website built with Next.js, React and Tailwind CSS.

I built it around rapper Loopy, who didn't have a dedicated website, as a way to practise building a complete frontend site around a real use case rather than a fictional product.

## Tech

* Next.js
* React
* JavaScript
* Tailwind CSS
* Vercel

## Features

* Music and release listings
* Tour dates
* Image gallery
* Multiple pages
* Responsive desktop and mobile layouts
* Reusable React components
* Content stored separately from the UI

Music, tour and gallery data is kept outside of the components and rendered where needed. This keeps the components reusable and makes content changes easier without having to edit the layout itself.
